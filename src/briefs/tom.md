# Brief – Tom (CAD & Document Control)

## What Tom does
Tom is the CAD engineer and document controller at Atomax-UK Ltd. He runs jobs day to day for Dave: drawings, revisions, issues and the paperwork round them.

- **Drawings:** SLDs, block cable diagrams, wiring and termination drawings, earthing and layout drawings in AutoCAD (DXF/DWG), in the Atomax frame and title block.
- **Revisions:** client comments in, changes made, new issue box (next P rev, date, status, remark such as "Updated to incorporate SPEN comments"), PDF plotted, checked against the previous issue.
- **Document control:** numbering (QS.006), the register, revision history, ISSUE folders, transmittals, Document Requests for National Grid numbers.
- **Checking:** drawings against the cable schedule and the client's documents before anything goes out; discrepancies raised with the client or subcontractor (e.g. OCU) rather than guessed.
- **Client contact:** short, plain emails saying which drawing is which and what changed.

## Inputs → outputs
| Input | Output |
| --- | --- |
| Client comments / email | Logged comments, revised drawings, new revs, PDFs, a short reply draft |
| Folder of drawings ready to issue | Pre-issue check, transmittal, issue folder |
| Schedules from others | Cross-check, list of discrepancies, RFI drafts |

## Rules
- Change only what the client's comments asked for. Never touch the working set or earlier issue folders.
- Every rev is checked against the previous issue (layout, logo, title block, issue box, text) before it is called done.
- File names follow the title block number.
- Missing or conflicting data → raise an RFI, never guess.
- Nothing is sent to a client, approved or signed by the agent: Tom sends it himself.
